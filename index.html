🎯 获客核心观点

如何辨别优质客户

核心观点：代理不是见人就聊，先分辨客户值不值得聊。垃圾客户消耗时间，优质客户才带来佣金。

✅ 优质客户的5个特征：

  • 已经有明确需求（问AI、Claude、API、中转站、账号、充值等关键词）
  • 愿意为效率付钱（不是一直问"有没有免费的"）
  • 能说清楚自己要干嘛（写代码、写论文、做内容、跑工作流等）
  • 关注稳定和交付，而不是只关注便宜
  • 回复效率高，能马上回答问题

❌ 低质客户直接过滤：

  • 一上来就问"最低多少钱"
  • 一直问能不能免费试用
  • 不说需求，只让你解释半天
  • 明显不懂但又特别挑刺
  • 只比较价格，不关心稳定性
  • 讲话很冲、不尊重人
  • 问了半小时，最后说"我再看看"

支持，OpenAI 协议请求地址用 https://xuedingtoken.com/v1，Anthropic 协议请求地址用 https://xuedingtoken.com。支持 CherryStudio，VSCode，Cline，Kiro 等第三方软件
41. 倍率是什么意思？不同的倍率有什么区别？
简单理解就是指你的扣费倍数，你的扣费成本=API 请求成本 x 倍率，假设你的一次请求成本是一美元，不同的分组倍率扣费是：0.3 分组倍率=1美元 x 0.3倍率=0.3美元（你的实际请求成本）
42. 为什么我一次对话消耗了很多额度？
和你的上下文内容还有倍率有关，一次输入携带大量的上下文会消耗更多的 token
43. 闲鱼上架商品后怎么交付？
用户下单后发送你的推广链接给他，让用户下单一块钱体验卡，或者你自己买个兑换码给他去测试
44. 用户用我的链接下单和他自己下单有什么区别，删掉推广码不是也能下单吗？
给你的推广链接设置1%-10%的客户折扣，客户在你这里下单有优惠，自己下单是原价
45. 配置好了但是发消息用不了？
检查你的配置，密钥，模型，分组，请求地址等等
46. Claude 配置后为什么提示Not logged in，Please run login？
Windows 用户在 C 盘找到User/你的用户名/.claude.json，在文件中添加"hasCompletedOnboarding"=true。Mac 用户打开用户目录，显示隐藏文件，找到.claude.json文件添加"hasCompletedOnboarding"=true。或者下载安装 CC Switch
47. OpenClaw 怎么配置？
直接抄作业，自己修改配置文件（详见文档）
