基础概念

什么是 API Key？

如果你是第一次接触 API，别慌——理解它比你想的简单得多。

🔑

API Key = 你的通行证

API Key 是一串字母和数字组成的密钥，就像会员卡号一样。有了它，AI 服务才知道「你是谁」，以及你有权限调用哪些模型。

📡

API = 远程调用 AI

不用在本地安装大模型（普通电脑也跑不动），通过 API 发送请求，云端 AI 返回结果。就像打电话请专家回答问题。

🛡️

安全须知

API Key 是你的私人密钥，绝不能泄露给他人。如果泄露，别人可以用你的额度。发现泄露后立即在控制台重新生成。

💰

按量计费

API 按输入/输出的 Token 数量计费，用多少扣多少，没有月租费。比订阅套餐灵活得多，适合轻度到中度使用。

CherryStudio 配置教程

CherryStudio 是目前最流行的 AI 桌面客户端之一，界面美观、操作简单，非常适合新手。

1

下载安装 CherryStudio

前往 CherryStudio 官网下载对应系统版本（支持 Windows / macOS / Linux），安装完成后打开应用。

2

添加自定义服务商

打开 CherryStudio → 设置 → 模型服务商 → 点击「添加自定义服务商」。名称填写「雪顶Token」或其他你喜欢的名字。

3

填入 API 地址和 Key

在服务商配置中：
• API 地址填入：https://api.xuedingtoken.com/v1
• API Key填入你刚才复制的 Key

4

选择模型，开始对话

点击模型下拉列表，选择 Claude Sonnet 4 / Opus 4 / Haiku 3.5 等模型，新建对话即可使用。搞定！

常见问题

FAQ

新手最常问的问题，都在这里了。

我没有编程基础，能用 API 吗？
完全可以。使用 CherryStudio 等桌面客户端，只需填写 API 地址和 Key，不需要写任何代码。和用网页版 AI 一样简单，只是换了个入口。
API 和 ChatGPT / Claude 官网有什么区别？
官网是封装好的对话界面，按月订阅收费（Pro $20/月）；API 是底层接口，按使用量付费，灵活度更高。通过 API 你可以在任意客户端使用，不受官网限制，且成本更低。
雪顶 Token 的 Key 安全吗？
雪顶 Token 是正规中转服务，Key 仅用于 API 请求鉴权，不会存储你的对话内容。建议定期更换 Key，并不要在公开场合分享。
CherryStudio 里模型列表是空的怎么办？
检查 API 地址是否填写正确（注意末尾的 /v1），确认 Key 有效。部分客户端需要手动添加模型 ID，如 claude-sonnet-4-20250514。
可以用在 Cursor / VS Code 编程吗？
可以。在 Cursor 的 Settings → Models 中填入 API 地址和 Key，或在 VS Code 安装 Cline / Continue 插件后配置即可。支持代码补全、对话和 Agent 模式。
额度用完了怎么办？
在雪顶 Token 控制台充值即可，支持微信/支付宝付款，充值秒到账。余额不足时 API 会返回错误提示，不会自动扣费。
