❓ 常见问题

FAQ · 快速解答疑惑

1. 如何成为代理？

注册数眼智能平台后，在"钱包管理"→"邀请奖励"中即可获取您的专属推广链接。客户通过您的链接注册后，将自动绑定为您的下级客户。

2. 佣金如何结算？

具体佣金比例和结算周期以平台官方政策为准，请联系客服或查看代理后台了解最新规则。

3. 客户如何绑定到我这里？

带有您推广码的链接跳转去注册后，用户会自动绑定到您的推荐里面。客户后续的所有消费都会持续给您返佣。

4. 支持哪些模型？

国外平台：Claude 3.5 Sonnet/Sonnet 4.7、GPT-4o/GPT-4o、DeepSeek V4 Pro/R1、Gemini 1.5 Flash、Midjourney V7、DALL-E 3、Flux Pro、Sora-2、VEO3、Kling 2.0等600+模型
国内平台：DeepSeek V4 Pro、GLM-5.1、Qwen3、Doubao、Kimi、MiniMax-M3等

5. 两个平台都需要注册吗？

不需要。根据您的客户需求选择相应平台推广即可。国外客户推荐使用 dataeyes.ai，国内客户推荐使用 shuyanai.com。

6. API Key 如何生成？

客户注册平台后，在平台界面自行生成 API Key。将 API Key 和平台提供的接口地址配置到常用工具中即可使用。

7. 企业用户可以开票吗？

可以的，支持开票。具体税率和开票内容可联系客服了解详情。

8. 客户自己下单不通过我怎么办？

您可以给自己的推广链接设置1%-10%的客户折扣优惠，这样客户通过您的链接下单有优惠，自然会选择从您这里购买。

9. 额度有期限限制吗？

额度永不过期。充值后可以随时使用，没有时间限制。

10. 如何设置代理折扣吸引客户？

您可以在推广后台设置1%-10%的客户折扣，客户通过您的专属链接下单可享受优惠，这样能有效吸引客户选择从您这里购买。

11. 平台除了API还有什么功能？

数眼智能不只是API中转平台。除了600+模型统一API，还提供：Agents在线工作台（对话/生图/生视频）、Web Reader网页解析、Deep Search深度搜索、AI Coding编程工具、短剧AI生产工具箱、以及可视化Workflow工作流。是一个全栈AI能力平台。
