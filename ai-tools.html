工具定位

Cline（原名 Claude Dev）是 VSCode 里最火的 AI 编程插件之一。它不是简单的代码补全，而是真正能自己读文件、写代码、跑命令、改 Bug 的 Agent。你只需要在对话框里说"帮我重构这个模块"，它会自动规划步骤、修改多个文件、运行测试，整个过程可视化。

Cline vs CherryStudio 怎么选？

简单区分：

  • CherryStudio：通用 AI 客户端，聊天 / 写作 / 翻译 / 知识库都能干
  • Cline：专攻代码场景，能直接操作你的项目文件、写代码、跑命令

两者完全可以共存——CherryStudio 处理日常对话和文档，Cline 处理写代码的任务。

推荐场景

  • 需要长链路任务自动化（重构、写测试、迁移框架）
  • 不想被某一家模型绑定，希望随时切换 Claude / GPT / DeepSeek
  • 重度 VSCode 用户，追求沉浸式编程不切换窗口

如何接入雪顶 API

  1. VSCode 扩展商店搜索 "Cline" 并安装
  2. 点击侧边栏 Cline 图标 → 右上角设置
  3. API Provider 选 "OpenAI Compatible"，Base URL 填 https://api.xuedingtoken.com/v1
  4. Model ID 填入模型名（如 claude-sonnet-4-5），填入 API Key 保存
  5. 开始用自然语言驱动 AI 写代码

常见问题 FAQ

Q1：CherryStudio 和 Cline 能同时用吗？会不会冲突？

完全可以。它们是独立的工具，CherryStudio 是桌面客户端，Cline 是 VSCode 插件，互不干扰。推荐组合：CherryStudio 处理日常对话和文档，Cline 处理写代码任务，各司其职。

Q2：中转 API 安全吗？会不会泄露我的对话数据？

主流中转平台（如雪顶Token）只是做请求转发，不存储对话内容，且全程 HTTPS 加密。安全性与官方 API 一致。但建议不要在对话中传输密码、密钥等敏感信息，无论用哪家服务都一样。

Q3：VSCode Copilot 能不能也用中转 API？

部分支持。Copilot 主体功能仍依赖 GitHub 官方授权，但通过它的 Chat 功能可以配置自定义模型端点。如果你希望完全摆脱 Copilot 订阅费，建议直接用 Cline 替代，体验更自由。
